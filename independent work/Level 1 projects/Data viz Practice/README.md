# Data Visualization Practice — World Happiness Report 2019

This folder is dedicated to practicing data visualization using the **World Happiness Report 2019** dataset.

The purpose of this exercise is not to build or train a machine-learning model. Instead, the focus is on improving the ability to choose appropriate visualizations, customize them clearly, and interpret the patterns shown by the data.

## Goals

- Practice common Level 1–2 data-science visualizations
- Understand which chart is appropriate for different types of questions
- Improve chart customization and readability
- Use visualizations to identify patterns, relationships, distributions, and outliers
- Develop the habit of creating plots that communicate a clear story rather than adding charts without purpose

## Dataset

The dataset contains country-level happiness information for 2019, including variables related to:

- Happiness score
- GDP per capita
- Social support
- Healthy life expectancy
- Freedom to make life choices
- Generosity
- Perceptions of corruption

## Tools

Visualization practice will mainly use:

- Pandas
- Matplotlib
- Seaborn

Power BI may also be used separately to experiment with chart design and customization before reproducing similar visualizations in Python.

## Scope

This is a focused visualization exercise. No predictive modelling will be performed.
