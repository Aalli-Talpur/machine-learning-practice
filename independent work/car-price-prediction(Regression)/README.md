# Car Price Prediction

A beginner-friendly machine learning project that predicts car prices using regression models.

## Project Goal

The goal of this project is to understand the complete regression workflow:

- explore and clean the dataset;
- identify useful features;
- prepare data for modelling;
- train a baseline regression model;
- evaluate model performance;
- compare different feature and model choices;
- improve predictions while avoiding overfitting and data leakage.
