# WHO Life Expectancy Regression

## Project Overview

This is a **Level 2 regression project** using the WHO Life Expectancy dataset. The project will be used to practise a more structured machine learning workflow with realistic data, including numerical and categorical features and missing values.

## Project Structure

- `data/` — dataset files
- `notebooks/` — EDA, experimentation, and model testing
- `src/` — reusable Python code developed from successful experiments

The project will be developed gradually as the dataset is explored and understood.
